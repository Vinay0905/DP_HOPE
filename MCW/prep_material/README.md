## 💡 Quick Revise Reference (From Past MulticoreWare Questions)
Here is a list of quick questions you should be ready to write on a shared screen or compiler:
*   *Coding*: Swap $a$ and $b$ without a third variable. (Use XOR: `a = a ^ b; b = a ^ b; a = a ^ b;` or Addition/Subtraction).
*   *Coding*: Insert into a Linked List (head, tail, middle).
*   *Coding*: Count character frequencies in a string using a hashmap, then print the count in sorted order.
*   *Concept*: What is a dangling pointer? How to avoid it?
*   *Concept*: Explain normalization and types of normal forms (1NF, 2NF, 3NF, BCNF) in DBMS.
*   *Concept*: What is the overflow condition of a circular queue?
